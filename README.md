# Inovegen Python Internship

Python projects completed during my Python development internship at **Inovegen** (about one month, 2026). Each task was assigned by the company and focused on building practical, real-world management applications using core Python.

## Projects

| # | Project | What it does |
|---|---------|--------------|
| 1 | **Contact Book** | Add, view, search, update, and delete contacts. |
| 2 | **Expense Tracker** | Records expenses and income and helps keep track of spending. |
| 3 | **Student Record System** | Manages student records with add, view, update, and delete operations. |
| 4 | **Inventory Management System** | Tracks stock items, quantities, and updates as inventory changes. |

## Skills Demonstrated

- Python fundamentals (functions, data structures, control flow)
- CRUD-based application design
- File and data handling
- Input validation and error handling
- Structuring small projects into clean, readable code

## Getting Started

```bash
git clone https://github.com/jibran11jb/Inovegen-Internship.git
cd Inovegen-Internship
python <project_file>.py
```

Replace `<project_file>` with the script of the project you want to run. Python 3.8 or newer is recommended.
